# Security policy

## Supported versions

Aion2Todo currently only support the current `master` branch. Fixes land there and are not backported.

| Version  | Supported |
| -------- | --------- |
| `master` | yes       |

## Reporting a vulnerability

**Please do not open a public issue for a security problem.**

Report it privately through GitHub, from [Security → Report a vulnerability](https://github.com/lamboley/aion2todo/security/advisories/new). That opens a private advisory visible only to you and the maintainer.
